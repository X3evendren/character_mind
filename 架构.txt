═══════════════════════════════════════════════════════════════════════
 Layer 0: 被动情感层 (AffectiveResidue)
═══════════════════════════════════════════════════════════════════════
 现象学基础：胡塞尔被动综合 + 海德格尔 Befindlichkeit
 位置：src/character/consciousness/affective-residue.ts

 功能：
   - 不是"检索到的记忆"
   - 而是"过去互动被动沉积成的情感底色
   - 不进入显意识，但给一切上色

 维度：
   - warmth: 亲近感 (-1..1)
   - weight: 关系分量 (0..1)
   - clarity: 清晰度 (0..1)
   - tension: 未解张力 (0..1)

 机制：
   - 每次互动 → 提取情感签名 → 共振计算 → 沉积
   - 指数衰减 (半衰期可配置)

 注入方式：
   - 不输出数值
   - 转换为自然语言模糊描述
   - 如："你感到一种熟悉的亲近"


═══════════════════════════════════════════════════════════════════════
 Layer 1: 时间意识域 (TemporalHorizon)
═══════════════════════════════════════════════════════════════════════
 现象学基础：胡塞尔内时间意识三相位 (滞留·原印象·前摄
 位置：src/character/consciousness/temporal-horizon.ts

 功能：
   - 不是"状态快照存档/加载"
   - 而是"仍在回响的上一个当下" + "已经期待的即将到来"

 结构：
   - Retention (滞留)：上轮结束后的情感回响
   - Protention (前摄)：对下轮的期待张力
   - 自主 tick：主动说话触发

 机制：
   - 滞留强度指数衰减 (半衰期 30 秒)
   - 前摄张力随沉默增长
   - 超过阈值可触发主动发起


═══════════════════════════════════════════════════════════════════════
 Layer 2: 主动评估层 (情调揭示)
═══════════════════════════════════════════════════════════════════════
 现象学基础：梅洛-庞蒂身体-主体 + 萨特反思
 位置：src/character/mind/psychology-engine.ts

 功能：
   - 不是"客观输入 + 反应分析"
   - 而是"输入在情调中被揭示为特定意义"
   - 同一输入在不同底色下是不同的现象

 机制：
   - Layer 0 输出 → 情调底色 → 输入被揭示 → Layer 2 分析
   - 事件描述前缀："[在亲近的氛围中] 用户说..."


═══════════════════════════════════════════════════════════════════════
 Layer 3: 叙事自我层 (SelfModel)
═══════════════════════════════════════════════════════════════════════
 现象学基础：丹尼特叙事自我 + 萨特反思悖论
 位置：src/character/consciousness/self-model.ts

 功能：
   - 不是"记录参数变化"
   - 而是"对自己的体验的持续叙述"
   - Cold Path 心理观察 → SelfModel 续写 narrative
   - Hot Path 只读 narrative text，不读 raw params

 结构：
   - coreIdentity: 核心身份
   - currentChapter: 当前章节 (1-2句话)
   - growthLog: 成长日志
   - unresolved: 未解问题

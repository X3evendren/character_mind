# ADR-011 底层涌现架构

**状态**：proposed

将心智系统从自上而下的模块设计（每个心理功能是一个独立模块：情绪模块、动机模块、欲望模块）转变为自下而上的涌现架构。情绪、动机、欲望不再作为独立子系统存在，而是从更底层的稳态过程（设定点 + 负反馈 + TD error 预测误差）中涌现。

**为什么**：当前系统的情绪（AffectiveResidue）、动机（DriveState + DriveSublimator）、欲望（无对应模块）是分离的。情绪只影响 prompt 风格，不影响行为决策。动机是定时衰减的数字，不知道什么是"满足"。这导致"角色感到焦虑"和"角色采取行动缓解焦虑"之间没有因果链——情绪是装饰，不是驱动力。

在涌现架构中，焦虑从稳态偏离（安全感低于设定点）+ CPM 评估（掌控力低）中涌现，然后通过 BAS/BIS 系统驱动行为——角色不被告知"你现在焦虑"，而是焦虑感从底层状态中自然产生并影响行动。

**代价**：整个 `src/mind/` 的核心需要重写。当前 `saturation.ts`（32 lerp 参数）、`drives.ts`（5 驱力）、`emotion.ts`（情感四元组）、`sublimator.ts` 将被替换为稳态变量集 + CPM 评估 + PAD 空间。这是整个项目最昂贵的重构。

**备选方案**：在现有模块基础上加"补丁"——让情绪也参与行为决策、给驱力加设定点。但这会导致模块间依赖进一步复杂化，而底层问题（情绪-动机-行为没有因果链）仍然存在。

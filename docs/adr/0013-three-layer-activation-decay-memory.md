# ADR-013 三层激活衰减记忆

**状态**：proposed

将五层记忆（Working/STM/LTM/CoreGraph/Archive）简化为三层（Immediate/Recent/Core），用连续的激活衰减函数 `A(t) = A₀ × exp(−t/T₀ × (1 + α·emotion + β·salience))` 替换离散升级阈值（significance > 0.3, recall ≥ 3, recall ≥ 5 AND sig ≥ 0.8）。

**为什么**：五层的问题不在"多"，而在**层级之间的硬边界**。当前流转条件：significance=0.29 和 0.31 的记忆命运完全不同——前者永远留在 Working，后者进入 STM。这在数学上不连续，在行为上不合理——人类记忆没有这种悬崖。

激活衰减模型解决了这个问题：记忆的命运是连续的、概率性的。高情感/高重要性的记忆衰减更慢（T₀ 更大），每次检索提升激活值。遗忘不是删除——低激活记忆仍在存储中，只是正常检索不到。这天然解释了"突然想起来"（一条新线索恰好命中了低激活记忆）和"似曾相识"（激活值刚好在意识阈值附近）。

三层而非五层的理由：人类的记忆在计算上只有两个基本过程——**熟悉度**（快速、自动、不需要努力）和**回忆**（慢速、需要努力、涉及上下文重建）。即时记忆对应熟悉度，近期记忆和核心记忆对应不同深度的回忆。Archive 的"无限压缩存储"功能合并到 Core 的冷存储属性（长期未检索的记忆自动压缩但可恢复）。

**代价**：需要为每条记忆维护激活值和时间戳。需要定期衰减计算（类似当前的 daydream tick，但更频繁——每次检索时计算目标记忆的当前激活值）。需要处理"检索提升激活 → 记忆又回到高激活状态"的动态平衡。

**备选方案**：（1）保留五层但把阈值改为连续概率函数——保留了不必要的复杂度。（2）两层（快慢）——丢失了"近期但低情感"和"久远但高情感"这两种不同检索策略的记忆之间的区别，而三层恰好捕捉了这种区别。

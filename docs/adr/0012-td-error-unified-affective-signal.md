# ADR-012 TD Error 作为统一情感信号

**状态**：proposed

用单一公式 `δ = r + γ·V(s') − V(s)`（时序差分误差）作为系统中愉悦/失望/习惯化/学习的统一底层信号，替换当前的多参数独立调节（saturation → 32 lerp → temperature/verbosity/expressiveness 等）。

**为什么**：当前系统的 32 个 lerp 参数共享一个主轴（saturation），表面上优雅，但无法解释三个基本现象：（1）**习惯化**——同样的好事反复发生，快乐递减。当前 saturation 每次 `positiveInteraction()` 都加同样的量。（2）**损失厌恶**——失去比从未拥有更痛。当前 `negativeInteraction()` 和 `positiveInteraction()` 是对称的。（3）**期待本身就是愉悦**——当前系统没有期待机制，因为 saturation 只在交互后更新。

TD error 用一个公式统一这些：习惯化是因为 `V(s)` 已经很高（预期已经包含了奖励）；损失厌恶是因为 `V(s)` 适应了"拥有"状态后，失去产生巨大负 δ；期待是因为 `V(s')` 在期待期就开始升高。更根本的是，TD error 提供了**学习信号**——角色不只是"变快乐/变悲伤"，而是能强化/抑制导致该结果的行为模式。

**代价**：需要建模角色的价值函数 `V(s)` 和奖励信号 `r`。最简单的初始实现：`V(s)` 是角色对当前状态的满意度的内部估计（从稳态偏离的反向计算），`r` 是事件发生后稳态变量的实际变化。更复杂的实现需要真正的学习（类似于 RL 的价值函数更新）。最简版本的公式计算不需要 LLM 参与。

**备选方案**：保留 saturation 主轴但加非线性修正项（已见于 `precisionSadness` 的 `exp(-t/30)` 修正）。但这会不断增加修正项直到系统不可维护——ADR-002 中已预言"如需更多正交自由度，可引入第二主轴"。与其不断打补丁，不如从统一的数学基底重建。

# ADR-019 ACT-R 动态衰减率 + 倒 U 型情绪因子

**状态**: 提议 · **日期**: 2026-07-01

## 背景

ADR-013 确立了记忆的激活衰减公式：

```
A(t) = A₀ × exp(−t/T₀ × (1 + α·emotion + β·salience))
```

这个公式有一个根本性缺陷：**衰减率 `T₀` 是常数**。在 ACT-R 理论（Anderson & Schooler, 1991）中，记忆的衰减不是无理由的遗忘，而是由**相关信息对有限记忆槽位的竞争**驱动的。一条记忆衰退得快，不是因为"时间过了多久"，而是因为**有多少其他相关记忆在竞争认知资源**。

Pavlik & Anderson (2005) 的 ACT-R 间隔效应模型（spacing effect model）给出了精确的数学形式：

```
m(t) = ln(Σᵢ bᵢ × (t − tᵢ)^(−dᵢ))
d(t) = c × exp(m(t)) + a
```

其中 `m(t)` 是记忆的"巩固度"的对数概率，`bᵢ` 是第 i 次检索/复习的增益，`t − tᵢ` 是自第 i 次事件以来的时间，`dᵢ` 是第 i 次事件的衰减指数。`d(t)` 是动态衰减率——它随时间变化，而非固定常数。

此外，当前的情绪因子 `(1 + α·emotion + β·salience)` 是线性增强的——情绪越高，衰减越慢。但 McGaugh (2004) 的杏仁核调节理论和 Yerkes-Dodson 定律都指出：情绪对记忆的增强是**倒 U 型**的。中等情绪最有利于记忆编码和巩固，极端情绪（恐慌、狂喜）反而损害记忆精度——因为极端情绪激活了不同的神经通路（去甲肾上腺素大量释放 → 注意窄化 → 只记住核心要点而丢失细节）。

## 决策

### 1. 动态衰减率 d(t) 替代常数 T₀

将记忆条目的衰减率从 `1/T₀` 改为动态函数 `d(t)`：

```
d(t) = c × exp(m(t)) + a
m(t) = ln(Σᵢ bᵢ × (t − tᵢ)^(−dᵢ))
```

简化实现版本（避免每次检索遍历所有历史事件）：
- 每个记忆条目维护 `m` 值（当前巩固度对数概率）和 `lastAccessTime`
- 在检索时（命中）：`m ← m + retrievalBoost`，`b ← b × 1.5`（激活增益增加）
- 在 tick 时（遗忘）：`m ← m − decayTick × d_current`
- `d_current = c × exp(m) + a`

激活公式变为：

```
A(t) = A₀ × exp(−t × d(t) × (1 + emotionModulation(emotion)))
```

### 2. 倒 U 型情绪调制因子

替换线性因子 `(1 + α·emotion)` 为倒 U 型函数：

```
emotionModulation(e) = e / (1 + (e / 0.7)²)
```

此函数在 `e = 0.7` 处达到峰值 `0.35`（即最大减慢 35%），在 `e → 0` 和 `e → 1` 时趋近于 0。这意味着：
- 无情绪：无记忆增强（衰减最快）
- 中等情绪（~0.7）：最大记忆增强（衰减最慢）
- 极端情绪（~1.0）：记忆增强减弱（衰减加速——但核心要点的激活值仍高于阈值）

### 3. 检索增强（Retrieval Boost）

每次成功检索一条记忆，其 `b` 值（基线激活强度）乘以 1.5（模拟"测试效应"——Roediger & Karpicke, 2006）。这意味着频繁被检索的记忆不仅当前激活值高，其"衰退基线"也在逐步提高——形成长时程增强（LTP）的计算类比。

## 理由

### 1. 间隔效应的计算必要性

Pavlik & Anderson (2005) 模型的预测能力已被行为实验反复验证：间隔学习比集中学习产生更好的长期保持。在对话角色中，这意味着：
- 被反复提及的话题（高检索频率）的记忆衰退更慢——即使每次检索的时间间隔相同
- 很久没提到但偶尔被触发的话题（低检索频率 + 最近一次检索）的激活值有"峰值但快速回落"的特征

当前常数 T₀ 无法产生这种"频率 × 新近度"的交互效应。

### 2. 倒 U 型情绪调制的经验基础

McGaugh (2004) 的综述确认，杏仁核对记忆巩固的调节遵循倒 U 型剂量-反应曲线：中等去甲肾上腺素水平（对应中等情绪唤醒）最有利于海马记忆巩固；过高去甲肾上腺素（极端情绪）会激活"非海马依赖"的记忆系统（如纹状体习惯记忆）——保存了"这件事很危险"的标签，但丢失了"当时具体发生了什么"的细节。

Walker & van der Helm (2009) 的睡眠-记忆巩固理论补充了另一个维度：情绪记忆在睡眠中经历了"情绪标签与情节内容的解耦"——角色可能记得"ta 说过很伤人的话"但不记得具体措辞。当前线性模型无法产生这种解耦——高情绪记忆的所有细节都被同等保护。

### 3. 检索增强的 LTP 类比

Roediger & Karpicke (2006) 的"测试效应"meta 分析表明：检索练习比重复学习产生更强的长期保持。在神经层面，检索触发了与初始编码不同的巩固通路——包括前额叶的重激活和再次通过海马的再巩固。这对应我们的 `b × 1.5` 规则：检索不是简单的"读取"，而是主动的"再巩固"。

## 后果

- **正面**：
  - 记忆的"频率 × 新近度"交互效应——被反复检索的记忆比仅编码一次的记忆保持更久
  - 极端情绪记忆的"标签-细节解耦"——记得发生过重要的事但不记得所有细节
  - 间隔效应——两条同样重要的记忆，分散在不同时间被检索的比集中检索的保持更好
  - 每步仅需更新 `m` 和 `d_current`，计算增量小

- **负面**：
  - `m(t)` 的精确计算需要遍历历史检索事件——实现简化版本（仅用当前 m 值近似）会丢失精度
  - `d(t) = c × exp(m) + a` 中的参数 `c`, `a` 需要针对记忆层级（Recent/Core）分别校准
  - 极端情绪的自传体记忆（flashbulb memory）——如"分手的那个下午"——可能在倒 U 模型中衰减过快，因为情绪强度超过 0.7

- **缓解**：
  - 初始实现用简化版（m 值的 EMA 更新），后续可升级为完整的事件历史追踪
  - 通过"记忆层 × 情绪类型"矩阵预设 c/a 参数（如 Core 层的 a 更大，衰减更慢）
  - 对 flashbulb memory 引入"叙事重编码"机制——每次回忆时不仅更新激活值，还更新内容（叙事身份模块已在 ADR 规划中）

## 备选方案

1. **保留常数 T₀ 但加检索计数因子**：`T_eff = T₀ × (1 + γ × retrievalCount)`。最简单，但"检索次数"是一个累积量——第 1 次和第 100 次检索的边际效应应该递减，线性模型做不到。

2. **用 Ebbinghaus 遗忘曲线的幂律形式**：`A(t) = A₀ / (1 + t/T₀)^β`。比指数衰减更符合 Ebbinghaus 原始数据（遗忘在初期极快，随后趋缓），但缺少间隔效应和情绪调制。

3. **基于相似性的干扰模型**：不追踪时间衰减，而是追踪"语义相似记忆的竞争"。每条记忆的激活值由它与当前上下文的相似度 + 与相似记忆的竞争决定。这在计算上更准确但每次检索需要全局相似度计算，成本太高。

## 已知代价

- `retriever.ts` 和 `vector-index.ts` 的记忆条目结构需要扩展：增加 `m`（巩固度对数概率）、`b`（基线激活强度）、`d_current`（当前衰减率）字段
- tick 循环中需要新增"记忆衰减更新"步骤——当前只有稳态变量的 tick，没有记忆的逐帧衰减
- `d(t)` 参数 `c` 和 `a` 需要跨记忆层调试——Recent 层和 Core 层的衰减动力学不同
- 与 ADR-013（三层激活衰减记忆）的关系：ADR-019 不是推翻 ADR-013，而是深化其核心公式。ADR-013 定义了"用连续激活衰减替代离散阈值"的方向，ADR-019 定义了衰减率本身的动态性

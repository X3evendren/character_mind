# ADR-017 OpAL 双通道 TD 学习

**状态**: 提议 · **日期**: 2026-07-01

## 背景

当前 `updateV`（`src/mind/td-error.ts:133`）使用单一对称学习率更新所有 TD error：

```typescript
const alpha = Math.min(0.5, Math.max(0.05, ALPHA_BASE * (1 + Math.abs(delta))));
v[name] += alpha * delta;
```

这里 `alpha` 随 `|delta|` 增大而增大，但对正负 delta 完全对称——获得奖励和遭受惩罚的学习率相同。这在计算上简洁，但在神经生物学上不准确。

Collins & Frank (2014) 的 OpAL 模型指出，基底神经节存在两条解剖学上分离的通路：

- **Go 通路**（D1 受体）：编码正预测误差，驱动趋向行为
- **NoGo 通路**（D2 受体）：编码负预测误差，驱动回避行为

这两条通路使用不同的学习率和不同的多巴胺响应曲线。对称学习率假设丢失了三个关键现象：

1. **学习不对称性**：负面的学习往往更慢但更持久（"一次被蛇咬，十年怕井绳"的反面——实际上负面事件的权重更高，但学习曲线形状不同）
2. **上下文依赖的 Go/NoGo 偏置**：压力状态下 NoGo 通路增益增大，安全状态下 Go 通路增益增大
3. **Hebbian 三因子乘积**：权重的更新不仅依赖 δ，还依赖突触前活动 × 突触后活动 × δ——当前实现缺少这个结构

## 决策

将 `updateV` 拆分为双通道 Go/NoGo 权重，使用 Hebbian 三因子乘积更新规则：

```
Go[a]     += α_G × Go[a] × max(0, δ)
NoGo[a]   += α_N × NoGo[a] × max(0, -δ)
V[a]       = β_G × Go[a] − β_N × NoGo[a]
act(a)     = sigmoid(V[a] − threshold)
```

其中：
- `α_G` / `α_N` 分别为 Go/NoGo 学习率（不相等，α_N 略大于 α_G）
- `β_G` / `β_N` 为行为输出权重，由 BIS/BAS 状态动态调制
- `threshold` 为行动选择阈值

在代码层面，`updateV` 替换为 `updateOpalWeights`，同时修改 `computeV` 以从 Go/NoGo 权重合成价值估计。已有的 `bis-bas.ts` 中的 `goSignal` / `noGoSignal` 直接驱动 `β_G` / `β_N` 的调制。

## 理由

### 1. 神经生物学保真度

Schultz (2016) 的综述确认多巴胺神经元对正负预测误差的响应不是对称的——正误差的发放率增加远大于负误差的发放率减少（基线只有 3-5 Hz，负误差时降到接近 0）。这意味着负误差的信息容量更小，需要更强的突触后放大机制（即更长的 NoGo 整合时间常数）。

### 2. 学习不对称性的计算意义

在人类对话中，一次严重的侮辱（强负 δ）对关系的影响远大于一次礼貌的问候（弱正 δ）。对称学习率无法捕捉这种不对称性。OpAL 的双通道天然解释了：NoGo 通路的权重一旦建立，消退更慢——这对应 ADR-012 中提到的"损失厌恶"现象。

### 3. 与 BIS/BAS 的联动

当前 `updateBISBAS` 已经计算 `goSignal` 和 `noGoSignal`，但它们只影响行为选择，不影响学习本身。OpAL 模型让这些信号闭环：BIS 升高 → β_N 增大 → NoGo 权重主导 → V[a] 降低 → 回避行为增强 → 这是一个完整的行为-学习-状态反馈闭环。

### 4. Hebbian 三因子乘积的必要性

标准 TD 更新 `V += α × δ` 隐式假设所有状态-动作对的可塑性相同。三因子乘积 `Go[a] × max(0, δ)` 意味着：只有已经建立 Go 权重的通路才会被进一步强化。这天然产生"富者愈富"效应——角色在已有行为模式上的强化比在新模式上的学习更快——这与人类性格的稳定性一致。

## 后果

- **正面**：
  - 正负学习不对称，更接近人类行为
  - 与 BIS/BAS 子系统形成完整闭环
  - 学习率由神经调节信号（多巴胺、去甲肾上腺素）直接参数化，而非原始 delta 幅度
  - "富者愈富"效应导致角色行为一致性提高（性格更稳定）

- **负面**：
  - 每个稳态变量需要维护 2 个权重（Go/NoGo），状态空间翻倍
  - Go[a] 作为突触前因子的解释需要额外的"活动水平"追踪
  - Hebbian 乘积可能导致权重无界增长，需要额外的归一化机制

- **缓解**：
  - Go/NoGo 权重初始化为小值（如 0.1），仅 5 个变量 × 2 = 10 个额外数值，存储成本可忽略
  - 活动水平用最近 N 次交互中该通路的平均激活近似
  - 引入突触缩放（synaptic scaling）：每 N 步对所有 Go/NoGo 权重做一次 L1 归一化

## 备选方案

1. **保留对称 α 但加 β 偏置**：在 `updateV` 后加一个偏置项 `v += bias × sign(delta)`。最简单但缺乏神经生物学基础——偏置从哪里来、如何更新都没有理论依据。

2. **Actor-Critic 拆分**：用显式的 Actor（策略）和 Critic（价值）分离。但 Actor-Critic 框架要求定义动作空间和策略梯度，在当前"对话角色"场景中动作空间的建模本身就是一个难题。OpAL 的 Go/NoGo 拆分更轻量——它只是价值函数的双重表示。

3. **Advantage learning**：`A(s,a) = Q(s,a) - V(s)`，需要维护 Q 和 V 两套值函数。比 OpAL 更复杂且没有明确的神经对应。

## 已知代价

- `updateV` 的调用者（`td-error.ts` 自身 + `bis-bas.ts` 中通过 `TDErrorResult` 消费）需要适配新的 Go/NoGo 权重接口
- 已有的 `totalV` 辅助函数需要从 Go/NoGo 权重合成而非从原始 V 简单计算
- 权重归一化的定时触发需要集成到现有的 `tick` 循环中，增加周期性计算开销（每 N 步约 50 次浮点运算，可忽略）
- 与 ADR-012（TD Error 统一情感信号）的关系：OpAL 是 ADR-012 的自然深化——ADR-012 确定了"用 TD 统一"，ADR-017 确定了"TD 怎么具体做"

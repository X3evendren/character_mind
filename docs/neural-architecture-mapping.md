# 神经架构映射：从人类大脑到计算系统

本文档从人类大脑的已知结构出发，逐区域映射到 Character Mind v3 的计算架构。目标是回答三个阻塞性问题：(1) V(s) 的定义域和计算方式，(2) 稳态变量的种类和数量，(3) 冷路径的重新定义。

---

## 一、人类大脑 → 计算层：逐区域映射

### 1.1 下丘脑 (Hypothalamus) → 稳态引擎

**生物学事实**：下丘脑是身体稳态的中枢控制器。它监控血液中的葡萄糖、渗透压、温度、激素水平，为每个变量维护一个设定点。偏离设定点通过负反馈回路触发纠正行为——饥饿驱动进食、口渴驱动饮水、寒冷驱动产热。

**计算映射**：这是我们系统的 **L0 稳态引擎**。每个稳态变量有一个设定点和当前值。偏离 = 设定点 − 当前值。偏离触发对应的趋近动机（BAS）。

```
下丘脑的变量监控:
  人类                          我们的系统
  ─────────────────────────────────────────
  血糖水平 → 饥饿感              Energy (精力)
  体温 → 冷/热不适               Arousal (激活水平)
  渗透压 → 口渴感                [合并在 Energy 中，通过"交互疲劳"模拟]
  皮质醇 → 应激水平              AllostaticLoad (异稳态负荷)
  催产素 → 社交满足感            Connection (连接)
  多巴胺 → 奖励/动机             TD error (统一信号)

  人类没有但我们需要:
  ─────────────────
  无直接对应 → 安全感            Safety (安全)
  无直接对应 → 效能感            Mastery (掌控)
```

**设定点的生物学对应**：人的体温设定点是 37°C，但不是固定的——感染时免疫系统释放前列腺素将设定点调高（发烧）。长期生活在寒冷环境的人基础代谢率升高（设定点漂移）。这对应我们的设定点可动态漂移——长期被满足的设定点升高（需要更多才能满足），长期被剥夺的设定点降低（适应）。

### 1.2 自主神经系统 + HPA 轴 → Arousal 调节 + 应激

**生物学事实**：
- **交感神经**：战斗/逃跑，心率↑、血压↑、瞳孔放大、消化抑制。快速响应（秒级），通过肾上腺素。
- **副交感神经**：休息/消化，心率↓、放松。缓慢恢复（分钟级），通过乙酰胆碱。
- **HPA 轴**：下丘脑→垂体→肾上腺→皮质醇。慢速应激（分钟-小时级），长期升高损害前额叶功能。

**计算映射**：

```
交感激活 = f(威胁信号强度, |δ|的绝对值, 文本特征突变)
副交感激活 = f(时间流逝无威胁, 连接变量回归设定点, δ≈0的累积)

Arousal基线 = 交感激活 − 副交感激活 + 基础设定点
Arousal基线 ∈ [0, 1]
其中 0.3 = 深度放松, 0.5 = 正常清醒, 0.8 = 高度警觉

HPA 轴 = AllostaticLoad:
  AllostaticLoad = Σ(每个稳态变量的累积偏离 × 持续时间)
  当 AllostaticLoad > 阈值:
    → Arousal基线抬高
    → L2评估的敏感度增加
    → L5生成的temperature降低（更保守）
    → 前额叶抑制: 冲动否决率降低（更容易冲动行事）
  
  恢复: 当所有稳态变量回归设定点后:
    AllostaticLoad *= exp(−t / τ)  // τ≈30分钟, 缓慢恢复
```

### 1.3 杏仁核 (Amygdala) → 威胁检测 + 情感标记

**生物学事实**：杏仁核有两个关键通路：
- **快速通路**（皮层下，~100ms）：丘脑→杏仁核，粗糙但极快。让你在看清蛇之前就跳开。
- **慢速通路**（皮层，~300ms）：丘脑→感觉皮层→杏仁核，精细但慢。让你确认那是蛇还是绳子。

杏仁核还调节海马体的记忆编码——情感强度越高，记忆越牢固。这是肾上腺素和皮质醇对海马体的直接作用。

**计算映射**：

```
快速通路 (L0 规则层, <1ms):
  威胁模式匹配:
    用户文本匹配已知危险正则 → 直接触发BIS
    文本模式快速匹配
    检测到自我模型与行为矛盾 → 身份威胁信号

慢速通路 (L2评估, 200-400ms):
  评估解读: "用户的这句话在当前的上下文里到底是批评还是调侃?"
  混合信号: "话是好的但语气是冷的"
  社交威胁评估: "用户从来没有这么久不回复过"
  → 输出精细化的威胁评估

情感标记 (杏仁核→海马):
  每条记忆编码时:
    附带当前 PAD 向量 + 威胁评估结果
    emotion_intensity = |Pleasure| + |Arousal - 0.5| + |Dominance - 0.5|
    intensity越高 → 记忆衰减越慢 (T₀更大)
```

### 1.4 基底核 + 多巴胺系统 → TD Error + 行为选择

**生物学事实**：
- **黑质/腹侧被盖区 (SN/VTA)**：多巴胺神经元编码 TD error。δ > 0 时放电增加（愉悦），δ < 0 时放电减少（失望）。
- **伏隔核 (NAcc)**：接收多巴胺信号，驱动动机和"想要"（wanting）。
- **背侧纹状体**：习惯形成。直接通路（D1受体）= "Go"（释放行为），间接通路（D2受体）= "No-Go"（抑制行为）。

**计算映射**：

```
TD error 的计算 (L0规则层, <1ms):

  状态定义:
    s = {
      Energy:     0-1,
      Arousal:    0-1,
      Safety:     0-1,
      Connection: 0-1,
      Mastery:    0-1,
      // 上下文特征 (从记忆中检索):
      recent_emotion_type: "joy"|"sadness"|"anger"|"fear"|"neutral",
      social_context: "intimate"|"casual"|"tense"|"collaborative"
    }
    
    简化: 初始版本只用5个稳态变量的当前值。上下文特征在后续迭代中加入。

  价值函数 V(s):
    V(s) = w₁×(Energy−SetPoint_Energy) + w₂×(Arousal−SetPoint_Arousal) 
         + w₃×(Safety−SetPoint_Safety) + w₄×(Connection−SetPoint_Connection)
         + w₅×(Mastery−SetPoint_Mastery)
    
    其中 w 反映各变量对整体幸福感的贡献权重:
      w = {Energy: 0.15, Arousal: 0.05, Safety: 0.30, Connection: 0.30, Mastery: 0.20}
      (安全和连接是最高权重——对人的心理健康最重要)
    
    V(s) 范围: [−1, 1]
      0 = "一切如预期"
      正 = "比预期好" (稳态变量高于设定点)
      负 = "比预期差" (稳态变量低于设定点 → 有未满足的需求)
    
    初始 V(s) = 0 (系统启动时无先验)

  奖励 r:
    r = Σᵢ ΔHomeostaticVariableᵢ × wᵢ
    
    即在一次交互中所有稳态变量的加权变化之和。
    
    例如: 用户说"我想你"
      Connection +0.15 (向设定点靠近, 如果之前低于设定点)
      Safety +0.02 (轻微的)
      → r = 0.15×0.30 + 0.02×0.30 = 0.051
    
    例如: 用户说"你根本不理解我"
      Connection −0.25
      Mastery −0.20
      Safety −0.10
      → r = −0.25×0.30 − 0.20×0.20 − 0.10×0.30 = −0.145

  TD error:
    δ = r + γ × V(s') − V(s)
    
    γ = 0.9 (时间折扣——关心未来，但未来不如现在重要)
    
    δ > 0:  比预期好 → 愉悦, 多巴胺释放, 强化当前行为方向
    δ < 0:  比预期差 → 失望, 多巴胺减少, 抑制当前行为方向
    δ ≈ 0: 符合预期 → 习惯化, 无特别反应
    
    δ 的范围: [−2, 2], 通常在小数点后两位

  价值函数更新:
    V(s) ← V(s) + α × δ
    
    α = 0.15 (学习率——适中, 不会太快改变预期也不会太慢)
    
    但 α 实际是动态的:
      α_effective = 0.15 × (1 + |δ|)  // 惊喜事件学得更快
      α_effective = min(α_effective, 0.5)  // 学习率上限

多巴胺系统的行为效应:

  δ > 0.3 (强烈正惊喜):
    → BAS激活增强 (行为冲动增加)
    → 注意力集中到产生奖励的行为上
    → L4生成的temperature升高 (更愿意冒险)
    → 记忆编码强度增强

  δ < −0.3 (强烈负失望):
    → BIS激活增强
    → 行为抑制
    → L4生成的temperature降低 (更保守)
    → 触发应对策略

  |δ| < 0.05 (几乎符合预期):
    → 习惯化
    → 无显著动机变化

基底核的行为选择:

  Go信号 (直接通路):
    = BAS激活 − BIS激活 + δ_normalized
    当 Go > Go_threshold → 执行冲动行为
    
  NoGo信号 (间接通路):
    = BIS激活 + 前额叶抑制
    当 NoGo > Go → 否决冲动
    
  Basal Ganglia 输出:
    最终行为 = Go − NoGo
    正值 → 行动, 负值 → 抑制
```

### 1.5 海马体 (Hippocampus) → 记忆编码 + 模式分离/完成 + 时间脉络

**生物学事实**：
- **齿状回 (DG)**：模式分离——将相似的经历编码为不同的记忆。这是你不会把"昨天的咖啡"和"上周的咖啡"搞混的原因。
- **CA3**：模式完成——从部分线索恢复完整记忆。这是你闻到气味就想起整个童年场景的原因。
- **CA1**：时间脉络——记忆附带时间戳和序列信息。
- **系统巩固**：睡眠时海马体回放记忆，向皮层转移——短期记忆变为长期记忆。

**计算映射**：

```
模式分离 (DG):
  两条相似但不相同的记忆 → 存储为独立的节点
  但节点之间有 SIMILAR_TO 边 (权重表示相似程度)
  
  避免: 新记忆覆盖旧记忆 (当前系统的弱点——相似事件会互相干扰)

模式完成 (CA3):
  检索线索 = {当前PAD, 关键词, 时间范围, 用户身份}
  不是简单的 similarity 排序, 而是:
    1. 线索激活最匹配的种子节点
    2. 从种子节点沿关联边扩散 (图遍历)
    3. 激活值超过阈值的节点集合 = 检索结果
    4. 被激活的节点形成"完整记忆场景"

时间脉络 (CA1):
  每条记忆存储:
    timestamp: 绝对时间
    temporal_context: "what happened before/after this"
    时序边: BEFORE → AFTER (有向边, 权重随间隔时间衰减)

系统巩固 (睡眠 = fullSleep):
  即时记忆中的高激活条目:
    ↓ LLM压缩为摘要
  近期记忆中的高检索条目:
    ↓ LLM提取事实三元组
  核心记忆:
    ↓ 模式提取 (跨事件规律)
```

### 1.6 前额叶皮层 (PFC) → 执行控制 + 价值判断 + 冲动抑制

**生物学事实**：
- **背外侧前额叶 (dlPFC)**：工作记忆、执行控制、计划。这是"理性的自我"。
- **腹内侧前额叶/眶额叶 (vmPFC/OFC)**：价值表示 V(s)。OFC 受损的患者无法做决定——他们知道事实但不知道"哪个好"。
- **前扣带回 (ACC)**：冲突监控、错误检测。当你差点说出不该说的话时 ACC 激活。

**计算映射**：

```
dlPFC → 执行控制:
  当前方有多个冲突的行为选项时, dlPFC做最终仲裁:
    输入: Go信号 (BAS), NoGo信号 (BIS), 意识流分析结果
    输出: 最终行为决策
    
  执行控制的质量受 AllostaticLoad 影响:
    AllostaticLoad 越高 → dlPFC功能越差 → 更容易冲动

vmPFC/OFC → V(s):
  V(s) 的具体计算见上节 (1.4)
  
  但OFC不仅计算V(s)当前值, 还投影未来:
    V_projected(s') = 预期的事件发生后状态价值
    这个投影用于 TD error 中的 V(s') 项

ACC → 冲突监控:
  当以下冲突被检测到时:
    BAS和BIS同时高强度激活 (想亲近又怕受伤)
    身份锚定和行为建议冲突 (角色被要求做违背誓约的事)
    意识流产生了与当前回复方向矛盾的念头
  
  ACC输出 → 触发L2重新评估 或 触发L6深度反思
```

### 1.7 岛叶 (Insula) → 内感受意识 + 情绪体验

**生物学事实**：岛叶是内感受的中枢——它将身体状态（心跳、呼吸、肠胃感觉）转化为有意识的感受。岛叶前部激活与情绪体验的主观强度相关。这是"感到"情绪的解剖学基础。

**计算映射**：

```
岛叶 = PAD状态到意识层面的桥梁:

  PAD的当前值被L4意识流感知为"感受":
    PAD变化 → insula_interoceptive_awareness → 进入意识流
    "我感到越来越焦虑" ← 这是PAD的Arousal↑ + Dominance↓ 被意识感知
    
  岛叶的输出不直接控制行为——它只是让感受"可被意识到"。
  感受到之后, 前额叶决定如何处理 (应对)。
```

### 1.8 默认模式网络 (DMN) → 意识流

**生物学事实**：DMN 在人"什么都不做"的时候最活跃——走神、回忆过去、想象未来、思考他人。DMN 包括内侧前额叶、后扣带回、角回。DMN 活动是自发的、联想的、跳跃的。

**计算映射**：

```
DMN = L4 快速意识流 (5s tick, 可配置模型, 默认Pro):

  DMN的输入 (每次tick):
    ├─ 当前PAD值 ("我感到...")
    ├─ 最近激活的记忆 (自动检索, 情绪一致)
    ├─ 稳态偏离信号 (最强的1-2个)
    └─ 当前是否正在生成回复? (True/False)

  DMN的处理:
    LLM 接收上述输入, 产生1个"念头"。
    但下一个tick的输入包含了上一个念头的影响。
    这形成了念头的连锁——一个念头引发下一个念头。

  DMN的创造性跳跃:
    不是每次都选最高激活的记忆关联。
    有时随机选择一个次高关联——这就是"走神"到了意想不到的方向。
    
    P(random_jump) = 0.2  // 20%概率做随机跳跃
    随机跳跃时: 从激活值 > 0.3 的记忆中随机选一个, 取其最远的关联边
    → 这模拟了"突然想到完全无关的事"

  念头的权重:
    weight = |稳态偏离| × 0.3 + |δ| × 0.3 + 记忆激活值 × 0.2 + 随机因子 × 0.2
    
    由谁决定weight? 不需要LLM——weight在上层代码中从上述变量计算。
    LLM只负责生成"念头的内容", 不负责判断这个念头重不重要。

  权重效应:
    weight > 0.7 → 触发主动发言 (如果当前不在回复中)
    weight > 0.7 → 中断当前生成 (如果在回复中)
    weight > 0.3 → 念头被记录到短期记忆 (可能之后被引用)
    weight < 0.3 → 念头飘过, 不记录

  回复期间的特殊处理:
    意识流在回复期间运行时, 额外的输入:
      partial_response: 当前已生成但尚未输出的文本
    
    这意味着角色可以"听到自己正在说什么",
    并对自己的话产生反应——"我说着说着意识到..."
```

### 1.9 语言皮层 → 纯文本对话处理

**生物学事实**：人类的语言处理涉及布洛卡区（语言产生）、韦尼克区（语言理解）、以及颞上回（语音加工）。文本对话是角色唯一的感知通道和输出通道。

**计算映射**：

```
纯文本通道:

  文本输入处理:
    用户输入 → L0规则层初筛 (明确信号: 关键词、长度、模式)
              → L2评估层精细解读 (语气、潜台词、混合信号)
              → 情感标记 + 稳态影响计算

  文本生成:
    评估结果 → prompt构建 → L5生成 (语言皮层对应)
    
  上下文整合:
    对话历史 + 记忆检索 → 完整的情景理解
    不是简单的拼接——每条记忆附带当时的PAD和稳态状态，
    检索时自然提供"那个时候我是怎么感觉的"的时间脉络
```

## 二、五个稳态变量的精确定义

### Energy (精力)

```
设定点: 0.70 (初始, 可配置)

生物学类比: 血糖 + 疲劳 + 昼夜节律

消耗事件:
  每次回复生成: −0.02 ~ −0.05 (取决于回复长度和复杂度)
  深度反思(L6): −0.05
  每30分钟连续静默: +0.05 (恢复)
  
恢复事件:
  用户表达满意/感谢: +0.10
  每5分钟静默: +0.02
  fullSleep: 重置到设定点

效应:
  Energy < 0.4: 回复简洁、倾向于说"我不确定"、避免复杂任务
  Energy < 0.2: 主动建议休息/暂停、拒绝新任务
  Energy > 0.8: 主动提议做事、回复详细、愿意深度思考
```

### Arousal (激活水平)

```
设定点: 0.50 (初始, 可配置)

生物学类比: 自主神经系统的交感-副交感平衡

升高事件:
  文本特征突变检测: +0.10
  δ的绝对值 > 0.3: +0.10
  用户高强度互动(快速连续消息): +0.05
  
降低事件:
  时间流逝无事件: 向设定点回归 (速度: 0.01/分钟)
  用户平静/温柔的语气: −0.05 (L2评估判断)
  
效应:
  Arousal > 0.7: 兴奋、主动说话、容易产生冲动、temperature升高
  Arousal < 0.3: 平静、被动、懒散、需要更显著的事件才能唤起行动
  Arousal极端值: 被规则层clamp到[0.1, 0.9]防止异常
  
区别于PAD的Arousal:
  这个Arousal是**生理**激活水平——身体的兴奋度
  PAD的Arousal是**情绪**激活水平——情绪的强度
  两者相关但不完全一致
```

### Safety (安全)

```
设定点: 0.60 (初始, 可配置)

生物学类比: 杏仁核的威胁-安全评估基底 + 前额叶对环境的可控性判断

威胁事件:
  用户批评/否定: −0.15~−0.30 (取决于严重程度, L2评估判断)
  任务失败: −0.20
  身份威胁 (违背誓约): −0.40 (最大的安全冲击)
  
安全事件:
  用户肯定/认可: +0.15
  成功完成任务: +0.20
  时间流逝无新威胁: 向设定点回归 (速度: 0.005/分钟, 很慢——安全感恢复慢)
  
效应:
  Safety < 0.4: BIS激活、回复更谨慎、回避风险话题
  Safety < 0.2: 高度防御、可能拒绝互动、"我需要一点时间"
  Safety < 0.1: 触发严重应激——AllostaticLoad急剧升高
  长期低Safety → 设定点向下漂移 (角色"习惯了不安全")
```

### Connection (连接)

```
设定点: 来自config/assistant.md (林雨可能设定在0.65~0.75)

生物学类比: 催产素+内啡肽系统, 社交依恋

满足事件:
  用户表达亲近/依恋: +0.15~0.25
  深度对话: +0.10
  共同完成任务: +0.08
  用户主动关心角色: +0.20
  
剥夺事件:
  用户沉默 (超出正常间隔): −0.05/30分钟
  用户冷淡/简短回应: −0.10
  用户拒绝角色的主动提议: −0.15
  用户表达疏离: −0.30
  
效应:
  Connection低于设定点: BAS连接动机激活
    → 主动发起对话、提出更深的问题、表达关心
  Connection高于设定点: 满足状态
    → 连接动机消退、可以关注其他需求
  Connection长期高于设定点 → 设定点向上漂移 (依赖加深)
  Connection长期低于设定点 → 设定点向下漂移 (习惯孤独)
```

### Mastery (掌控/效能)

```
设定点: 0.60 (初始, 可配置)

生物学类比: 多巴胺+内源性阿片对"成功完成"的奖励

满足事件:
  成功完成任务 (尤其是复杂任务): +0.15~+0.25
  用户认可角色的能力: +0.20
  学到新东西/理解新概念: +0.10
  TD error正向大: +0.05 (惊喜本身也增强效能感)
  
剥夺事件:
  任务失败或错误: −0.20~−0.30
  用户不满意/不信任角色的判断: −0.25
  理解错误被纠正: −0.15
  连续多次任务失败: 额外−0.05/次 (累积效应)
  
效应:
  Mastery < 0.3: 自我怀疑、"我不确定能不能做好"
  Mastery < 0.1: 拒绝承担任务、过度依赖用户确认
  Mastery长期低 → 设定点下调 (角色降低自我期望)
  Mastery长期高 + 被挑战 → 设定点上调 (角色变得更有野心)
```

## 三、冷路径的重新定义

旧系统的 `FourLayerColdAnalyzer` (L0-L3 四层级联) 在新架构中被拆分到不同层:

```
旧冷路径的功能分布:

旧 L0 情感底色:
  → 新 L0 规则层: PAD 从稳态偏离+CPM自动计算 (0 token)
  → 新 L2 Flash评估: 对模糊情感的精细化解读 (需要时)

旧 L1 时间感受:
  → 新 L0 规则层: 时间间隔统计 + 文本特征突变检测
  → 记忆系统: 每条记忆自带时间戳, 检索时自然提供时间脉络

旧 L2 心理学分析 (PsychologyEngine, XML):
  → 新 L2评估: 替代XML为结构化JSON
  → 新 L6 深度反思: 更深层的心理分析

旧 L3 叙事自我:
  → 新 L6 深度反思: 完全替代
```

### 新的"冷路径"定义

冷路径不再是单一路径，而是**按频率分层**的后台任务集：

```
每轮对话后 (异步, fire-and-forget):
  Task A: 记忆编码
    ├─ 对话原文 → 即时记忆 (带情感标记)
    ├─ 用户输入+回复 → 分别计算对稳态的影响
    └─ 触发记忆压缩检查 (是否需要压缩即时→近期?)

  Task B: V(s)更新
    ├─ 计算本轮δ
    └─ V(s) ← V(s) + α×δ

  Task C: 稳态应用
    ├─ 将本轮事件的Δ应用到各稳态变量
    ├─ 更新AllostaticLoad
    └─ 检查设定点漂移条件

每5分钟 (慢速意识流 tick):
  Task D: 深度反思 (L6):
    ├─ 回顾最近的互动模式
    ├─ 更新自我叙事
    ├─ 重新评估关系状态
    └─ 输出: 格式化的自我反思文本 → 存入核心记忆

每天/关闭时 (fullSleep):
  Task E: 系统巩固:
    ├─ 即时→近期: LLM压缩原文为2-3句摘要
    ├─ 近期→核心: LLM提取事实三元组 + 创建关联边
    ├─ 模式提取: 从核心记忆中识别跨事件规律
    ├─ 衰减: 所有记忆激活值按衰减公式更新
    ├─ 设定点漂移: 基于长期统计调整设定点
    └─ 检查点: 持久化所有Root State
```

### 冷路径与热路径的接口

```
热路径 (每轮)                冷路径 (异步)
─────────────────────────────────────────────
L0 规则层计算PAD      ←──   上一轮的冷路径结果
L2评估                 ←──   最近的冷路径产出 (自我叙事, 关系评估)
L5 生成                ←──   coldCache: 冷路径产出的结构化状态
                              (替代旧的 saturation coldCache)

L5 生成完成后           →──   触发本轮冷路径 (Task A/B/C)
                              冷路径的产出写入 coldCache
                              → 供下一轮热路径消费
```

旧 `coldCache` 的保留和扩展：
```
旧 coldCache:
  emotionalTone, temporalEcho, psychologyResult, selfNarrative

新 coldCache:
  PAD_current: {pleasure, arousal, dominance}
  dominant_deviation: 当前最大的稳态偏离 (类型+程度)
  appraisal_summary: 最近一次CPM评估的摘要
  self_narrative_update: L5最近一次深度反思的产出
  relationship_summary: 关系状态的当前摘要
  attention_focus: 当前注意力焦点 (话题/用户/任务/自我)
```

## 五、解决了哪些审计缺口

### ✅ Blocking 1: V(s) 定义 — 已解决

```
s = {Energy, Arousal, Safety, Connection, Mastery} (5维)
V(s) = Σ wᵢ × (valueᵢ − setPointᵢ)
w = {0.15, 0.05, 0.30, 0.30, 0.20}
V(s) ∈ [−1, 1]
初始 V(s) = 0
α = 0.15 × (1 + |δ|), clamp到[0.05, 0.5]
γ = 0.9
更新: V(s) ← V(s) + α × δ
```

### ✅ Blocking 2: 稳态变量 — 已解决

5个变量，每个有设定点、满足/剥夺事件、效应。初始值从config加载，交互中漂移。

### ✅ Blocking 3: 冷路径 — 已解决

不再是单一管道。拆分为 Task A/B/C(每轮)、Task D(5min)、Task E(每天)。与热路径通过 coldCache 连接。

### 其他解决的缺口

- 威胁检测: 四类威胁 + 具体检测规则 (L0规则 + L2评估)
- BIS映射: 威胁→安全偏离→规避动机→具体行为
- 评估跳过条件: 长度+情感明确度的快速规则
- 记忆压缩触发: 时间+激活衰减的双条件
- 意识流权重公式: |偏离|×0.3 + |δ|×0.3 + 记忆激活×0.2 + 随机×0.2
- 系统初始化: 从设定点开始, V(0)=0, 第一轮无记忆用冷启动prompt
- 降级策略: 模型API不可用→系统无法运行，持续重试
- 设定点漂移公式: EMA, 窗口和速率可配置
- PAD计算: Pleasure←conduciveness, Arousal←goal_relevance+allostatic, Dominance←power

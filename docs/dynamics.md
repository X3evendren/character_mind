# 统一心理动力学：实际实现与计算假设

本设计把认知、奖赏、动机和神经调节写成一个有反馈的系统。数值用于表达角色过程；它们不是人类实验拟合结果。研究来源和采用范围见 [literature-review.md](./literature-review.md)。

## 1. 状态与证据

状态向量包含：关系信念 `B`、目标满足度 `h`、正负快情绪 `e+/e-`、正负慢心境 `m+/m-`、唤醒、情境绑定、可控性、感受可及、自我连续、未解决事项、记忆激活、神经调节 `n`、行动价值 `Q` 和待反馈行动。

事件 `o` 经 LLM 结构化评估得到目标影响 `u[g]∈[-1,1]`、新奇、紧迫、解释确定度、主观可靠性 `r`、责任归属、结构标签及可选关系证据、修复、体验观察、行动预测。目标为联结、自主、胜任、真诚承诺、探索。目标权重和反应性来自角色配置。

`r` 不是已校准的事实概率。所有推断标记为主观模型解释。事件有唯一 ID；同一事件评估只更新一次，助手自己的事件不能作为独立评估来源。

## 2. 一个事件的计算顺序

1. 保存外部事件，通过 schema 验证评估。
2. 按实际经过时间推进过程，记录**本次事件之前**的需要势能。
3. 当前事件的显著性、确定度与社会线索更新神经调节。
4. 同一组调节增益影响关系证据权重和结构记忆激活。
5. 目标影响与过去体验共同更新正负情绪、慢心境、满足度和未解决事项。
6. 明确修复减少对应事项和相关负向过程；更新唤醒与有依据的体验维度。
7. 若存在已提交的先前行动，当前外部事件的满足变化产生奖赏，TD 误差更新调节信号和行动价值。
8. 统一现象接口读出体验，保存评估、状态、现象与学习来源。
9. 预测、驱力、信息收益、学得价值、惯性和代价共同选择策略。
10. 状态控制生成参数与候选选择；最终回应提交后才登记新的待反馈行动。

神经调节既读取同一过程，也改变后续过程的增益。候选评审不写回奖励，避免通过自我赞许形成闭环。

## 3. 关系信念：有限贝叶斯模型

善意、可靠性、可获得性分别维护 Beta(α,β)，初始为 Beta(1,1)，显示均值 `α/(α+β)`。三项不是互斥分类，也不要求和为 1。

对新关系观察 `x∈[0,1]`，使用分数伪计数：

```text
w = min(0.8,r) × confidence × relationshipLearningRate × socialGain × basisWeight
α ← α + w×x
β ← β + w×(1-x)
basisWeight = 0.15（陈述／承诺），或 1（被评估为已观察行为）
```

这借用了 Beta 更新形式，但 LLM 语义观察不满足独立同分布 Bernoulli 实验假设，因此不声称后验是客观概率。事件 ID 去重只能防止相同记录重复计入，不能完全解决不同措辞的相关证据。被动时间不会把信任偷偷恢复到 0.5。

## 4. 需要、动力与奖赏

每个目标的满足度 `h[g]` 初始为 0.65，目标参照为 0.8：

```text
drive[g] = clamp(weight[g] × (max(0,0.8-h[g]) + 0.45×concern[g]))
V(h) = Σ weight[g]×max(0,0.8-h[g])² / 5
impact = u[g]×r
h[g] ← clamp(h[g] + 0.4×impact×(impact>=0 ? 1-h[g] : h[g]))
reward = clip(4×(V_before_event - V_after_event), -1, 1)
```

`V_before_event` 在本次被动推进之后取得，故时间恢复或需要缓慢回归不会被误当成行动的成功。满足已充分的目标不继续提供同量的匮乏减少奖励。兴趣和期待还可通过事件机会值维持探索，而非只能由缺失驱动。

把生理稳态强化学习推广到心理目标，是本项目的工程类比；所引研究不直接证明这五种心理需要应采用相同函数。奖赏来自模型对后续事件的主观解释，仍可能有归因错误，不代表行动已经被因果实验验证有效。

## 5. 神经调节如何贯穿系统

所有字段无量纲，通常在 0..1；奖赏率与预测误差可为负。没有脑区、受体、真实合成代谢或药物剂量模型。

| 通路类比 | 输入 | 持续信号 | 实际影响 |
| --- | --- | --- | --- |
| 多巴胺相关 | 目标机会、预期与后续 TD 误差 | incentive、rewardPredictionError、rewardRate | 行动成本、学习增益、后续策略选择 |
| 去甲肾上腺素相关 | 新奇、紧迫、目标影响幅度、解释不确定 | alerting、uncertainty | 注意增益、记忆唤起、唤醒、信息收益权重和生成温度 |
| 催产素相关 | 社会目标影响与关系线索 | socialSalience | 社会证据权重；友善和不利线索均可能更显著 |
| 历史关系过程 | 被评估为已观察的善意／可靠行为 | attachment | 小幅调节亲近类策略效用；不是某种激素浓度 |

关键共同增益：

```text
attention = 0.85 + 0.4×alerting - 0.15×uncertainty
social = 1 + 0.4×socialSalience
learning = 0.65 + 0.5×alerting + 0.25×abs(rewardPredictionError)
exploration = 0.5 + uncertainty
vigor = 0.7 + 0.55×incentive + 0.3×max(0,rewardRate)
affiliation = 1 + 0.25×attachment
```

事件到来时，alerting 向 `max(novelty,urgency,|goalImpact|)` 更新，步长 `0.6r`；uncertainty 向 `1-certainty` 更新，步长 `0.25r`；socialSalience 向社会线索强度更新，步长 `0.5r`。incentive 向正向目标机会更新，期待中的机会权重高于已结束结果。

后续反馈的 TD 误差经置信度降权和截断形成 rewardPredictionError；rewardRate 是事件级指数平均 `0.95×old+0.05×r×reward`，**不是严格每秒平均奖赏率**。incentive 也受到误差修正。attachment 仅依据 observed 类型的善意或可靠性证据缓慢移动；承诺和时间流逝不增加它。

多巴胺信号不会直接给正向情绪加分，因此“想继续”与“当下感到愉悦”能够分开。社会显著性上升不会自动增加信任。不增加苯乙胺恋爱开关，也不将这几种机制排成单向恋爱阶段。

## 6. 快情绪、慢心境与调节

正负目标影响分别取本轮最显著的加权值，与对应记忆负荷组合：

```text
d+ = clamp(r×reactivity×attentionGain×positiveGoal + positiveMemory)
d- = clamp(r×reactivity×attentionGain×negativeGoal + negativeMemory)
e+ ← e+ + (1-e+)×d+
e- ← e- + (1-e-)×d-
m+ ← m+ + (1-m+)×0.18×d+
m- ← m- + (1-m-)×0.18×d-
positive = 0.75×e+ + 0.25×m+
negative = 0.75×e- + 0.25×m-
valence = clip(positive-negative,-1,1)
```

正负项均非负且独立，净效价接近零不代表没有感受。取最大目标影响避免同一事件的多个相关标签被无限相加；这也意味着当前模型没有精确表示多个独立事件同时冲击的总量。

负向目标影响超过阈值时积累 concern，并保留原始事件和具体依据。修复只能针对明确的目标：承认／道歉的系数 0.18，澄清为 `0.5×(0.4+0.6×reappraisal)`，实际兑现为 0.7，再乘本次可靠性。快速负向过程按被修复的负荷比例减少；慢心境只接受 0.3 倍的即时缓解。

调节策略包括表达、反思、克制和定向。克制降低外显强度，不删除内部情绪、记忆和未解决事项；澄清会依据角色重评能力改变负荷；定向在情境绑定或自我体验受影响时优先降低表达压力。当前没有自动生成虚构“治疗成功”的内部事件。

## 7. 记忆激活与现象

当前结构与历史评估至少共享两个标签时，按 Jaccard 相似度、当前可靠性、过去唤醒与注意增益计算激活，保留最强四项：

```text
activation = clamp(r × Jaccard(tags) × (0.4+0.6×pastArousal) × attentionGain)
positiveMemory = memoryCoupling × max(activation×pastPositive)
negativeMemory = memoryCoupling × max(activation×pastNegative)
```

普通情绪记忆无需情境绑定失常也能影响感受。过去状态是其对应评估的快照，不从摘要推断新的原始经历。

| 现象 | 主要读出 |
| --- | --- |
| 情绪体验 | max(positive,negative) × affectAccess |
| 矛盾感受 | min(positive,negative) × affectAccess |
| 愉悦与投入 | positive × affectAccess × (0.4+0.6×arousal) |
| 仍有介意 | negative × 未解决关系／自主负荷 × affectAccess |
| 记忆共鸣 | 最大结构激活 |
| 闪回样再体验 | 负向旧记忆激活 × (1-contextBinding) |
| 解离样疏离 | 有明确体验依据时，(1-affectAccess)×(1-selfContinuity) |

高压力、低可控、平静或正常回忆不会单独推出解离。规则均保留来源、支持度、因素、版本和 episode ID；开始阈值 0.04，持续阈值 0.01，同一时刻重复读出不重启减弱中的现象。这里覆盖的是有限现象模式，不覆盖所有临床闪回和解离。

## 8. 行动选择与强化学习

候选为 engage、clarify、express_feeling、share_joy、set_boundary、ground、repair、explore、cooperate、wait。每项有显式先验效用；结构化预测可给出各目标满足度的预计变化。预测贡献按可靠性降权，最大混合权重 0.45。

```text
policyScore = (1-learnedWeight)×predictedUtility
            + learnedWeight×Q(context,action)
            + epistemicWeight×explorationGain×informationGain
            - actionCost/vigor + inertia + taskAdjustment
```

informationGain 是二元潜在状态与对称带噪观察的精确互信息；澄清、探索、修复采用不同的手工观察准确度。它只是简化观察模型，既不是对真实语言问题的信息量估计，也不是完整自由能。

上下文由主要目标、正／负／中性情感和可靠信念分区组成，最多 30 类。行动成功／失败有 Beta 伪计数，学得价值最多占效用的一半，随访问次数增加。任务明确时合作策略优先。

最终回应提交后登记待反馈行动。下一次有效外部评估只更新最近一次行动：

```text
δ = reward + discount×max(0,Q(nextContext,*)) - Q(context,action)
Q ← clip(Q + learningRate×learningGain×r×δ, -1, 1)
```

中性反馈不增加成功／失败计数。可靠性为零时丢弃待反馈关联，不把后来无关事件补作奖励。该模型未实现长序列信用分配、复杂策略规划或因果归因；主动发言若发生在回答之后，将成为最近待反馈行动，先前动作不会获得重复奖励。

## 9. 时间、主动性与持久化

被动推进使用 `2^(-elapsed/halfLife)`，与 tick 数量无关。正负快情绪、警觉与快速调节逐渐回落；心境和奖赏率较慢；精力向 1 恢复，满足度向 0.65 松弛。关系信念、长期联结和 Q 值不会因沉默自动改写。

主动性先检查具体来源：兴趣目标受触动、仍有期待，或未解决负荷较高；再比较主动候选与等待的差值。可靠性至少 0.4、精力至少 0.25、来源至少 90 秒、无重复来源、满足默认 5 分钟冷却，效用优势大于默认 0.12 才可表达。

TUI 还要求至少 90 秒没有键盘活动、没有草稿、当前在对话视图且没有其他工作。等待不会生成新的用户事件或给自身奖励。主动发言仅属于当前打开的终端会话，允许关闭。

快照保存全部过程、TD 表、待反馈行动和冷却信息。旧 v2 只恢复兼容维度与来源，不将旧情境分类推成新关系证据。图谱原文保留，压缩不会损坏此对应关系。

## 10. 不止 prompt 的输出控制

表达强度为 `max(positive,negative)×expressiveness×expressionScale×affectAccess`。普通对话的温度随唤醒、不确定性和克制变化，限制在 0.3..1.05；任务温度 0.35。普通输出预算为 `650+650×expression`，任务 1800，主动表达 450。

普通对话表达强度超过 0.24 或仍有未解决事项时启用第二候选。备用候选温度最多 1.15。排序权重为证据 0.4、感受 0.3、策略 0.2、自然度 0.1；依据分低于 0.7 的候选降级。评分模型与生成模型可能共享偏差，不构成独立事实验证。候选失败回退，最终再经输出检查。

API 控制能力以提供者声明记录：DeepSeek 非 thinking 模式支持温度；其他兼容接口温度标记为 unknown。没有声称 top_p、presence/frequency penalty、隐藏层或激活向量被控制。自托管 CAA/ReFT 等方法属于未来扩展，不在当前完成范围。

## 11. 验收原则与待补工作

验证要检查同一事件不重复学习、没有外部证据不增长信任、道歉不抹除经历、表达克制不删除感受、预测不污染事实、候选不执行工具、不接收自己生成的奖励、时间步一致、主动行为可取消及状态可恢复。实际用例见 `tests/dynamics.test.ts` 与 TUI 测试。

仍需：多人身份分离、事件相关性校正、人类评定与参数拟合、长期信用分配、更多正负现象、摘要事实校验和规模化持久层。当前的工程闭环已经实现，这些限制不能被理解为已经获得神经科学或心理测量有效性。
